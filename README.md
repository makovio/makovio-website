# Makovio Labs Website

Startseite für Makovio Labs: kostenlose Apps für macOS und Android. Das Repository enthält derzeit ein statisches, responsives Grundgerüst. Die Website ist noch nicht veröffentlicht.

## Aktueller Stand

- `index.html` und `styles.css` bilden die Startseite ohne Build-Schritt oder externe Abhängigkeiten.
- HomeBar und LightScout sind als **geplant** gekennzeichnet. Für sie gibt es hier noch keine Downloads oder zugesagten Erscheinungstermine.
- Buy Me a Coffee ist als freiwillige Unterstützung vorgesehen. Ein Link wird erst ergänzt, wenn ein bestätigtes Ziel vorliegt.
- Es gibt noch keine angegebene Domain und keine als veröffentlicht aufgeführte App.

## Lokal ansehen

`index.html` im Browser öffnen oder im Repository-Verzeichnis `python3 -m http.server 8000` starten und `http://localhost:8000` aufrufen.

## Nächste Inhalte

Für eine veröffentlichte App erst nach Freigabe ergänzen: bestätigte Beschreibung, Plattformen, Systemanforderungen, Screenshots, Versionsstand, Download-Ziel und Datenschutzinformationen. Keine Platzhalter-Downloads oder erfundenen Links einbauen.

## Mitarbeit mit Codex

Änderungen auf einem eigenen Branch vornehmen und als Pull Request prüfen. Die Projektregeln stehen in [`AGENTS.md`](AGENTS.md); die PR-Vorlage fragt insbesondere nach überprüften Links und dem Veröffentlichungsstatus.
