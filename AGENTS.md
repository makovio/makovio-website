# Arbeitsregeln für Codex

Dieses Repository ist die geplante Website von Makovio Labs. Arbeite in Deutsch, sofern die jeweilige Aufgabe nichts anderes verlangt.

## Verlässliche Inhalte

- Beschreibe HomeBar und LightScout als künftige Projekte, bis eine Veröffentlichung ausdrücklich bestätigt ist.
- Erfinde keine Apps, Funktionen, Veröffentlichungstermine, Domains, Download-URLs oder Buy-Me-a-Coffee-Links.
- Ergänze Links, Screenshots und Produktangaben nur anhand bestätigter Quellen oder ausdrücklicher Vorgaben.
- Lasse fehlende Informationen weg und kennzeichne den Status sachlich.

## Umsetzung

- Halte die Website statisch, zugänglich und ohne externe Abhängigkeiten, solange eine neue Architektur nicht benötigt wird.
- Verwende semantisches HTML, gut lesbare Kontraste und mobile Layouts.
- Prüfe nach sichtbaren Änderungen mindestens Desktop- und Mobilansicht sowie Tastaturnavigation.
- Ändere Inhalte auf einem Arbeitsbranch und fasse Anlass, Änderung und Prüfung im Pull Request zusammen.
- Veröffentliche die Website oder App-Downloads erst nach einer ausdrücklichen Aufgabe dazu.
